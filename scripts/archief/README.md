# Archief: oude Firestore-regels

Hier staan regelbestanden die niet meer gelden. Ze blijven bewaard om terug te kunnen kijken of om in een noodgeval terug te draaien.

**Publiceer deze bestanden nooit zomaar.** Ze zijn losser dan de huidige `firestore.rules`.

- `firestore.rules.migratie`: tijdelijke overgangsregels voor de P0c-migratie. Die geven één account toegang tot de hele database.
- `firestore.rules.voor-P0c`: de regels van vóór P0c (19 november 2026).
- `firestore.rules.voor-P0d`: de regels van vóór P0d (24 november 2026). Dit is de terugvaloptie van P0d, zie `.claude/docs/P0d.md`.
